How it works

How it works

  1. 1. Agent signs the request

    The shopping agent includes a cryptographic signature (Ed25519, RFC 9421) and optionally a mandate signed by the shopper, proving who it is and what it's allowed to buy.

  2. 2. ProveTheBuy verifies at checkout

    Your middleware checks the signature against the card-network key directory (Visa, Mastercard), validates the mandate limits, and records everything in a hash-chained evidence ledger.

  3. 3. My Agents dashboard

    See every agent that has bought from your store: which protocol it uses, its key directory entry, first-seen date, order count, dispute rate, and cross-merchant reputation.

  4. 4. Dispute lands months later

    The evidence record still verifies. ProveTheBuy generates a fight-or-accept score, an evidence pack, and a PDF certificate — ready to submit to Stripe or export for Visa TC40/SAFE and Mastercard formats.

Visa Trusted Agent Protocol (TAP)

RFC 9421 HTTP Message Signatures with Ed25519. Agent keys registered in a Visa key directory. 100+ partners. ProveTheBuy verifies signatures against the directory in real time.

Mastercard Agent Pay

Agentic Tokens + Verifiable Intent. Tokenises the user's mandate (not just agent identity) so the merchant can verify what the shopper actually authorised. ProveTheBuy validates the full mandate chain.

Google Universal Commerce Protocol

Full-journey standard from discovery to post-purchase. 20+ partners including Shopify, Walmart, Target. ProveTheBuy captures and records agent-side request data at the checkout step.

AP2 (Agent-to-Platform Protocol)

Cart and intent mandate verification. The shopper and merchant co-sign the cart; the agent can only proceed with the exact items agreed. ProveTheBuy verifies both signatures and checks constraints.
